# Проектная работа "Посмотри в окно"

## Описание проекта
"Посмотри в окно" — это интерактивное веб-приложение, которое позволяет пользователям просматривать видео из разных городов в разное время суток. Проект реализован в рамках обучения на курсе "Веб-разработчик" в Яндекс Практикуме.

В основе проекта лежит уже готовая логика на JavaScript и HTML-разметка. Задачей было написать CSS-стили, чтобы интерфейс в точности соответствовал предоставленному макету из Figma, сохранив при этом всю функциональность приложения.

## Функциональность
* **Просмотр видео:** Выбор видео из списка карточек обновляет основной видеоплеер.
* **Поиск:** Работает форма поиска по городу и времени суток (утро, день, ночь).
* **Динамическая загрузка:** Кнопка "Показать ещё" подгружает дополнительные карточки.
* **Состояния загрузки и ошибок:** При поиске отображаются кастомные прелоадеры, а в случае отсутствия результатов — блок с ошибкой.
* **Доступность (A11y):** Кастомные чекбоксы и кнопки доступны для навигации с клавиатуры, имеют состояния `:focus-visible` и поддерживают скрытие нативных элементов через класс `.visually-hidden`.

## Используемые технологии
* **HTML5:** Семантическая разметка, теги `<template>` для динамического рендеринга карточек.
* **CSS3:** 
  * Flexbox для построения сетки и выравнивания элементов.
  * Кастомные элементы форм (стилизация чекбоксов через псевдоэлементы `::after`).
  * Позиционирование (`position: relative` для прелоадеров).
  * Свойство `object-fit` для корректного отображения видео и изображений.
  * Кастомный скроллбар (`::-webkit-scrollbar`).
* **JavaScript:** Готовая логика работы приложения (запросы к API, рендеринг шаблонов, обработка событий).
